# a brutally playful reality check

Micro web app pensata come reality check rapido, ironico e minimale.

## Stack

- Next.js
- React
- Tailwind CSS
- motore locale per score, categoria, verdict e indicatori

## Run

```bash
npm.cmd install
npm.cmd run dev
```

## Architettura MVP

1. `/` pagina input full screen, tutta in italiano
2. `/risultato` loading dedicato e risultato finale
3. meter minimale, quattro indicatori, share e retry
